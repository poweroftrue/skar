# SKAR - سكار

A radical minimalist fragrance brand for silent rebels. Pure black. No compromise.

## Quick Start

```bash
python3 -m http.server 8000
# Open http://localhost:8000
```

## Project Structure

```
/skar
├── index.html          # Minimal HTML structure
├── style.css           # Pitch black aesthetics
├── main.js             # Three.js bottles & scroll magic
├── design-language.md  # Brand soul & design guide
└── thebrand.md         # Original brand brief
```

## Design Philosophy

**Read `design-language.md` first.** It contains the soul of SKAR.

Key principles:
- Pitch black (#000000) only
- MADE Soulmaze typography
- Apple-style scroll interactions
- Three unique 3D bottle designs
- Radical minimalism

## Technical Stack

- **Three.js** - 3D perfume bottles with realistic glass
- **Vanilla JS** - No frameworks, pure performance
- **CSS** - Minimal, no preprocessors needed
- **Fonts** - MADE Soulmaze via CDN

## Development Guidelines

Before adding anything:
1. Can it be simpler?
2. Does it maintain the void?
3. Is it scroll-driven?
4. Does it feel like SKAR?
